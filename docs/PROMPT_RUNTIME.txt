  ENGLISH<TAB>CHINESE
Template rules (critical — matching is exact after normalisation):
- Reconstruct the exact runtime English line, including punctuation, spaces and markup like {{rules|...}}, {{c|→}}, {{r|♥}}.
- Replace EVERY number that is computed or may vary — including its leading +/- sign, decimals, and dice expressions like 1d6, 2d3+2 — with a single '#'. E.g. "+20% chance" → "#% chance"; "{{rules|1d6}}" → "{{rules|#}}". Fixed literal numbers that never vary may also be '#' (safer).
- Replace any non-numeric variable text (an adjective from GetAdjective(), a creature/item name, a stat name chosen at runtime, a pluralized word) with {0}, {1}, ... in order of appearance.
- The Chinese side must contain exactly the same number of '#' (you may use '#1', '#2' to reorder numbers) and the same {n} markers, and the same markup tags.
- If a line has several variants (if/else branches, singular/plural like "1 turn"/"# turns"), write each variant as its own line.
- Lines that are pure numbers/markup: skip.
- One template per line; no header. Use \n inside a field only if the runtime string has no line break there (normally not needed).
